# INDICE_REPOS_RICARDO

Índice público, breve y filtrable de los repositorios públicos de Ricardo.

- Explica la función real de cada proyecto.
- Indica la versión publicada o, si el proyecto no usa versiones, el estado actual de `main`.
- Enlaza la web publicada cuando existe.
- Ofrece descarga directa del APK en Android y del script principal en Python.
- Excluye todos los repositorios privados.

Web: <https://ricardoyf.github.io/INDICE_REPOS_RICARDO/>

Versión del índice: **v1.0**.
